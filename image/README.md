# HAKONIWA 想定画面

最初の小さな世界と、約100日間の創造を経た世界を比較するためのビジュアルリファレンスです。どちらも実装を完全に固定する完成稿ではなく、世界とゲームUIが同時に成長する方向性を共有するためのコンセプト画像です。

## Day 1 — はじまりの村

![Day 1の想定画面](day-1-village.jpg)

- 一画面に収まる、静かで余白の多い長方形の村
- 願いの木、家、井戸、池、短い道と一人の観測者だけが存在
- 神託、創世記、願い、図鑑、庭という最初のUI
- 戦闘、通貨、クエスト、HPなどはまだ世界に存在しない

## Day 100 — 育った村とゲームUI

![Day 100の想定画面](day-100-village.jpg)

- Day 1の願いの木、池、井戸、道を残しながら村が発展
- 家、畑、市場、住民、橋、魚、虫、花、焚き火跡などが増加
- 季節、天候、時間、レベル、HP、クエスト、ミニマップ、持ち物、道具、技など、100日間で生まれたゲームシステムをUIへ追加
- 画面中央の村を主役に保ち、機能が増えても一般的なMMOのような過密UIにはしない

## 生成情報

- 生成方式: Gemini APIによる画像生成
- モデル: `gemini-3.1-flash-image`
- 共通方針: 16:9、トップビュー、オリジナルの16-bit風ピクセルRPG、実際に操作できそうなゲーム画面、同じランドマークと画面言語を継承
- Day 1プロンプトの要点: 未完成で静かな村、最小限の世界要素とUI、広い余白、戦闘・HP・通貨なし
- Day 100プロンプトの要点: Day 1画像を参照し、同じ村を農業・交易・住民・生態系とともに発展させ、季節やRPGシステムの誕生をUIの増加として可視化

画像内の細かな文言や数値は確定仕様ではありません。実装時は [`docs/FIRST_GAME_SPEC.md`](../docs/FIRST_GAME_SPEC.md) と、日々の創世記で実際に誕生した概念を正とします。
