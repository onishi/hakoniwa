# 体験の進化計画 — できることが増えていく100日

## 0. この計画の目的

裏側の仕組みの予定は [開発ロードマップ](ROADMAP.md) にある。**この文書が扱うのは、観測者の側から見て何ができるようになるかだけである。**

二つを分ける理由は、進み方が違うためである。裏側には、適用器、スナップショット、検証器のように、完成しても画面が1ピクセルも変わらない仕事が多い。一方で世界への約束は「明日は今日と少し違う」である。**裏側が見えない仕事をしている日にも、体験の変化は別に出す。**

複数人が同時に訪れたときの見え方は [複数の観測者が遊ぶ世界](SHARED_WORLD_EXPERIENCE.md) に定める。Day 1には他者の姿も痕跡も見えず、Day 9から匿名の痕跡が残り、Day 80から他者の願いへ世界内で触れられる。Day 100でも、同時刻に集まることを遊ぶ条件にはしない。

### 何を前に出すか

この世界の骨格は観測と発見にあるが、**それだけでは最初の1週間がもたない。** 世界の仕組みに気づく面白さは、気づくだけの中身が世界に溜まってから効く。したがって100日の前半は、**やれることが目に見えて増えていくこと**を前に出す。

- **動きを見つける** — 魚影、虫、小さな生き物が行き先を知らせる
- **集める** — 拾う、釣る、育てる、採る。持てるものが増える
- **広がる** — 歩ける場所が増える
- **種類** — 世界にあるものの数が増える
- 拾えるものは種類ごとに形・色・輪郭を変え、同じ見た目を別の種類へ使い回さない。名前を読まなくても、木の実・枝・石を画面で見分けられることを受け入れ条件にする。

### 入手元と使い道を一組にする

世界に置くものは、地面に落ちたアイテムとして数を増やさない。必ず「どこから、どの行為で入手するか」と「何に使うか」を定義する。

| 入手元 | 行為 | 入手するもの | 使い道 |
| --- | --- | --- | --- |
| 実のなる果樹 | 果樹へアクション | 果物 | 庭へ植える、置く、他のレシピの材料 |
| 岩・倒木 | 道具を持ってアクション | 鉱石・木材 | クラフト、置く |
| 耕した庭 | 種や果物を持ってアクション | 作物 | 採る、置く、次の種の材料 |
| 区画固有の場所 | その場所でアクション | 固有素材 | 置く、クラフト、後続の交換 |
| 魚影のある池 | 借りた竿で釣る | 魚と観察記録 | 池へ戻す。後日に加工も選べる |
| 虫のいる草むら | 観察するか網で捕る | 観察記録または虫 | 花の近くへ戻す |

すでに存在する採集物にも、入手元と使い道を後から必ず割り当てる。使い道が決まらない新しい種類は公開候補へ入れない。置くことは最低限の使い道だが、置く以外の意味が必要な素材は、次の節目までにクラフト・栽培・交換のどれかへつなぐ。

1回10分の訪問設計とDAY 1〜50の日ごとの中心行為は [毎日10分遊べる体験計画](DAILY_PLAY_PLAN.md) に定める。日ごとに「入手元→使い道→結果」が一つ成立し、次の訪問の理由が残ることを検証の合格条件にする。

DAY 50の再設計では、動きを先に見せる。DAY 3に魚影、DAY 5に岸辺の生き物、DAY 10に釣って戻す行為、DAY 20に魚・虫・庭から選べる循環を置く。旧DAY 50の主要な入手・利用はDAY 30までに前倒しする。詳細と公開ゲートは [DAY 50再設計](DAY50_REVISED_PLAN.md) にまとめる。以下の日付は新しい公開候補であり、旧進化テスト版の実装実績を示さない。

仕組みへの気づき（時刻や天候で世界が変わる、条件を満たすと発見になる）は後半へ回す。消すのではなく、順番を変える。

### 守るもの

- **ボタンは増やさない。** 増えるのは「できること」であって操作方法ではない。植える、汲む、渡すは、位置と対象によって意味が変わる同じアクションとして表現する。行為を決めるのは対象の状態と、**手に何を持っているか**である。100日ぶんの検証は [Day 100のゲーム仕様](MIDDLE_GAME_SPEC.md) にある。
- **集めることと図鑑を混ぜない。** 集めるのは持ち物と素材であり、使うためにある。図鑑は観察の記録であり、埋めるものではない。完成率も総数も出さない。
- 周回で量産させない。取り逃しを作らない。連続ログイン報酬、スタミナ、ガチャは入れない。
- 告知しない。増えたことは世界の中から見つけさせる。

## 3. 10日ごとの体験

### Day 1–10 動くものを見つけ、釣る

池に波紋と魚影、岸辺に小さな生き物が現れる。木の実を拾い、竿を借り、魚を釣って池へ戻す。**最初の10日で「見る」から「触る」「生き物へ返す」へ進む。**

- 集まる: 木の実、枝、石、羽、貝殻
- 広さ: 一画面のまま
- 種類: 5 → 12
- 語れること: 昨日まで動かなかった池に魚影がいる、釣れる、戻せる

### Day 11–20 虫と庭をつなぐ

草むらの虫を観察し、網で捕って戻す。花を置くと次の訪問で虫が来る。果樹の実を採り、自分の庭へ植える。**生き物が来る条件と、育ちを待つ時間が意味を持ちはじめる。**

- 集まる: 種、苗、実、花
- 広さ: 一画面のまま
- 種類: 12 → 20
- 語れること: 虫が花へ来た、植えたものが日をまたいで育つ
- 注意: 毎日の水やりを義務にしない。数日空けても枯らさない

### Day 21–30 世界が広がる（一度目）

庭の外へ出られる。隣の区画には違う魚や虫の居場所、岩や倒木がある。道具で素材を採り、作業場所で組み合わせる。**広さそのものではなく、見られるものと採れるものの違いを体験にする。**

- 集まる: 隣の区画に固有のもの
- 広さ: 100 → 220タイル
- 種類: 20 → 30
- 語れること: 外がある、ここにしかない生き物と素材がある、作ったものを置ける

### Day 31–40 生息場所と反応を深める

釣りと虫の行為はすでにできる。同じ池でも浅瀬や天候で魚影の通り道が変わり、花の色によって来る虫が変わる。**同じ場所への再訪で違う動きが見つかる。**

- 集まる: 浅瀬・花・草むらごとに異なる魚、虫、植物
- 広さ: 220のまま
- 種類: 30 → 40
- 語れること: 同じ池にも違う魚がいる、花で虫の訪れ方が変わる
- 注意: 動きを増やしても入力や観察文の読みやすさを妨げない

### Day 41–50 種類と生息関係を増やす

手続きスプライトが入り、神が作った新種がその日のうちに姿を持って現れる。魚・虫・植物の関係と行き先が増える。**新種は名前と色だけでなく、動きと居場所で見分けられる。**

- 集まる: 新種の実、新種の素材
- 広さ: 340タイルへ
- 種類: 40 → 55
- 語れること: 見たことのない姿と動き、居場所のつながり

### Day 51–60 生態を重ねる

動く存在は序盤からいる。この時期は生き物同士や季節との関係を足し、庭へ来る条件を複数にする。

- 集まる: 生き物が落としたもの、巣、卵
- 広さ: 340のまま
- 種類: 55 → 68
- 語れること: 生き物同士が影響し、同じ庭でも季節で訪れ方が変わる
- 注意: 捕獲を主目的にしない。避ける・待つ選択を残す

### Day 61–70 地形が増える

水辺、林、丘。地形ごとに採れるものが分かれる。**広さの二度目の拡張は、地形の種類とセットで出す。**

- 集まる: 水辺、林、丘それぞれの素材
- 広さ: 340 → 600タイル
- 種類: 68 → 80
- 語れること: 渡る、登る、そこにしかないもの

### Day 71–80 住人と、やりとり

NPCが暮らしはじめる。渡す、交換する。集めたものが他者との関係になる。

- 集まる: 交換でしか得られないもの
- 広さ: 600のまま
- 種類: 80 → 92
- 語れること: 人がいる、渡した、交換した
- 注意: 依頼一覧にしない。好感度の作業を作らない

### Day 81–90 世界の側の仕組みが見えてくる

ここで初めて、時刻と天候を前に出す。同じ場所が朝と夕で違い、雨の日にしか採れないものがある。**すでに集める習慣があるため、仕組みの変化が「採れるものの変化」として体感される。**

- 集まる: 時刻・天候に固有のもの
- 広さ: 600 → 900タイル
- 種類: 92 → 102
- 語れること: 夜、雨、季節、そのとき限りのもの
- 注意: 来られない時間帯への不安を作らない。逃したものは別の機会に戻る

### Day 91–100 村の外

危険のある場所へ出られる。避けられる敵、持ち帰る素材。100日の歴史を辿れるようになる。

- 集まる: 外にしかない素材
- 広さ: 900 → 1,200タイル
- 種類: 102 → 112
- 語れること: 外、危険、持ち帰り、100日の因果
- 注意: 戦闘を主ループにしない。訪問あたりの戦闘時間比を見る

## 4. 毎日の変化の供給源

節目でない日も、必ず何かが変わる。供給源は六つある。

| 供給源 | 観測者から見えるもの |
| --- | --- |
| 新しい存在 | 昨日までなかったものが、どこかに在る |
| 既存の変化 | 知っているものの状態、位置、様子が変わる |
| 新しい法則 | 世界の振る舞いそのものが変わる |
| 願いへの応答 | 誰かの願いが、直接ではない形で世界に現れる |
| 修復と訂正 | 壊れたもの、誤っていたものが直る |
| 沈黙 | 神が何も創らなかったことが、記録として残る |

沈黙を除く五つが初日から使える。世界はD1のデータになっており、存在を増やすのも既存のものを変えるのも、データベースへの書き込みだけで済む。コードのデプロイを待つ必要はない。

沈黙は「何もない日」ではない。創世日記にその日の項目が残り、日付は飛ばない。**ただし、できることが増えていく前半では沈黙を連続させない。**

## 5. 見た目の語彙をどう増やすか

種類を増やすうえで、Day 40までは**見た目が制約になる。** ただし魚影・波紋・小動物・虫の最小の動きはDAY 2〜15に専用の語彙として先に作る。新種を増やす際は既存の姿と動きを組み合わせ、名前だけを変えない。

そこで二つを分ける。

- **見た目の語彙**（描ける姿の種類）は、まとめて足す。10個単位でデプロイする。
- **個々の存在**は、その語彙を使ってデータで毎日足す。

前半の「種類が増える」体験は、この二段構えで作る。Day 41–50で手続きスプライトが入ると、語彙の追加自体がデータになり、制約が外れる。

## 6. 増えすぎないための制約

やれることを増やすほど、作品の芯を外す危険が増える。次を守る。

- 集めたものに**完成率や総数を出さない。** 持ち物は使うためにあり、埋めるためではない。
- **反復で量産させない。** 希少なものは、条件の組み合わせと時間から生まれる。
- **取り逃しを作らない。** その日限りのものを作らない。逃しても別の形で戻る。
- 一日に公開する中心概念は**ひとつ**。できることを二つ同時に増やさない。
- 新しくできるようになったことを、**説明モーダルで先に明かさない。**

## 7. 伝え方

変化を伝える場所は創世日記だけとする。機能名もバージョンも書かない。

| 書かない | 書く |
| --- | --- |
| 「持ち物機能を実装しました」 | 「手に持てるようにしました。落ちているものを、拾ってみてください」 |
| 「栽培システムを追加しました」 | 「土に埋めたものが、芽を出すようにしました」 |
| 「新エリアを開放しました」 | 「柵の向こうに、道を伸ばしました」 |
| 「バグを修正しました」 | 「池の底が抜けていました。直しましたが、水は少し濁ったままです」 |

## 8. 届いているかの確認

「増やした」ことではなく、「増えたことに気づかれ、使われた」ことを見る。

- 新しくできるようになったことを、その週のうちに一度でも行った割合
- 拾ったものを使った割合（持っているだけで終わっていないか）
- 広がった場所へ実際に行った割合
- 前半（Day 1–40）で、訪問あたりに行った行為の種類が増えているか
- 沈黙の日の離脱が、通常日と比べて増えていないか
- 後半で仕組みを前に出したとき、前半に離れた人が戻っているか

**増やした日に誰も使わなければ、それは増やしていないのと同じである。** 使われない場合は、数を増やす前に、置き場所と気づかせ方を見直す。
