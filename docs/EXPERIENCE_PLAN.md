# 体験の進化計画 — 毎日「今日はこれが変わった」

## 0. この計画の目的

裏側の仕組みの予定は [開発ロードマップ](ROADMAP.md) にある。**この文書が扱うのは、観測者の側から見て何が変わるかだけである。**

二つを分ける理由は単純で、両者の進み方が違うためである。裏側には、適用器、スナップショット、検証器のように、完成しても観測者の画面が1ピクセルも変わらない仕事が多い。一方で世界への約束は「明日は今日と少し違う」である（[コンセプト](CONCEPT.md)）。**したがって、裏側が見えない仕事をしている日にも、体験の変化は別の供給源から出さなければならない。**

原則は三つ。

1. **世界日が進んだ日は、観測者が気づける変化が必ず一つある。** 変化の大きさは問わない。花がひとつ開いていれば足りる。
2. **告知しない。** 「〜を追加しました」と書かない。変化は世界の内側の言葉と見た目から発見させる。
3. **気づかなかった人が損をしない。** 見逃した変化は消えず、後日でも観察と日記から辿れる。

## 1. 「今日の変化」の供給源

毎日の変化は、次の六つのいずれかとして現れる。裏側の開発が進んでいない日でも、このうち複数は常に使える。

| 供給源 | 観測者から見えるもの | 使える時期 |
| --- | --- | --- |
| 新しい存在 | 昨日までなかったものが、どこかに在る | Day 2から |
| 既存の変化 | 知っているものの状態、位置、様子が変わる | Day 2から |
| 新しい法則 | 世界の振る舞いそのものが変わる（夜が来る、雨が降る） | 能力が入った日から |
| 願いへの応答 | 誰かの願いが、直接ではない形で世界に現れる | Day 2から |
| 修復と訂正 | 壊れたもの、誤っていたものが直る。その経緯も残る | Day 2から |
| 沈黙 | 神が何も創らなかったことが、記録として残る | Day 2から |

**沈黙を除く五つが初日から使える。** 世界がD1のデータになっているため、存在を増やすのも、既存のものを変えるのも、データベースへの書き込みだけで済む。コードのデプロイを待つ必要はない。

## 2. 変化を出せる量の制約

体験の厚みは、裏側の能力によって上限が決まる。時期ごとに、出せる変化の量と質が変わる。

| 時期 | 変化の作り方 | 一日に出せる量 | 体験の質 |
| --- | --- | --- | --- |
| Day 2–27 | 編集者がデータを書き込む | 存在を一つ増やせる | 世界に物が増えていく |
| Day 28–31 | 創造サイクルを通して公開 | 一日ひとつの中心概念 | 検証と承認を経た運用の開始 |
| Day 32以降 | 法則の層が増えていく | 同上。加えて時刻・天候で毎日違う | 同じ場所が毎日違って見える |

**Day 2–27は、見た目の語彙が制約になる。** 存在を増やすこと自体はデータで済むが、スプライトは手書きのCSS図形しかないため、まったく見たことのない姿のものは出せない（手続きスプライトはDay 51–60）。この時期は、既存の姿を使える範囲で増やし、言葉と配置で差を作る。世界がまだ小さな庭ひとつであることは、観測者にとっても自然であり、隠す必要はない。

## 3. 沈黙をどう見せるか

沈黙は「何もない日」ではない。神が創らなかったという出来事であり、そのように見せる。

- 創世日記にその日の項目を作り、創造がなかったことを短く記す。
- 日付が飛ばない。空白のまま残さない。
- 障害で日次処理が失敗した日も、途中状態を見せず沈黙として扱う。
- 沈黙を連続させない。続く場合は、その理由が後の世界で意味を持つようにする。

沈黙の日でも、観測者の側では天候と時刻が動き、他者の痕跡が増える。**世界が止まったようには見えない。**

## 4. 体験の「初めて」

100日のうち、観測者が**それまで一度も経験していないこと**に出会う日を挙げる。左が世界日、右がそれを支える裏側の能力（[開発ロードマップ](ROADMAP.md) の段に対応）。

| 世界日 | 観測者が初めて体験すること | 必要な裏側 |
| --- | --- | --- |
| 2 | 昨日と違う日になっている。日記が二件になる | 世界日の進行（初日前に完了） |
| 2 | 世界に、昨日までなかったものが在る | 世界のデータ化（初日前に完了） |
| 2 | 同じ対象の言葉が、前と違う | 観察文のデータ化（初日前に完了） |

| 42 | 二度目に調べると、違うことが書いてある | 初回と再観察の区別 |
| 43 | 芽が、日をまたいで育っていく | 成長段階 |

| 50 | 見たことのあるものが「現在は確認されていない」になる | 消滅の履歴 |
| 60 | 見たことのない姿の生き物に出会う | 手続きスプライト |
| 65 | 高い場所から見下ろす | 標高 |

**この表が、実質的な「今日の目玉」の一覧である。** ここに載っていない日は、毎日の創造（新しい存在、既存の変化、願いへの応答）で差を作る。

## 5. 10日ごとの体験

### Day 1–10 世界が動きはじめる

一画面の庭のまま、日付が進む。変化は小さく、言葉が中心になる。観測者が最初に理解するのは「ここは毎日見に来る場所だ」ということであり、内容の豊かさではない。

- 語れること: 昨日との差、日記が増えていくこと、沈黙した日があること
- まだ無い: 新しい存在、時間、他者の気配

### Day 11–20 物が増えはじめる

世界に置けるものが増え、庭に少しずつ物が足される。観測者から見ると、ここで初めて「増えていく世界」になる。

- 語れること: 昨日までなかったものが在る、既存の対象の言葉が変わる
- まだ無い: 時間、天候、発見の記録

### Day 21–30 毎日ひとつが約束になる

創造サイクルが回り始め、一日ひとつの中心概念が毎日公開される。ここから「今日はこれが変わった」を毎日言える状態になる。

- 語れること: 毎日の中心概念、願いへの最初の応答
- 注意: 量が出るようになるため、一日に複数を出したくなる。**中心概念は一つに保つ**

### Day 31–40 世界に時間が流れる

昼夜、天候、季節が入る。**新しい存在を一つも増やさなくても、毎日違う世界になる。** 100日の中で、体験の密度が最も大きく変わる10日間。

- 語れること: 夜、雨、季節の兆し、時刻で姿を変えるもの
- 副作用: 訪問時刻によって見えるものが変わるため、来られない時間帯への不安を作らないよう、取り逃しの表現を避ける

### Day 41–50 見ることが記録になる

観察が状態の関数になり、発見と図鑑が入る。観測者の行為が初めて世界に残る。

- 語れること: 二度目の観察で違うこと、初めての発見、図鑑
- 注意: 図鑑は埋めるものではない。総数も完成率も出さない

### Day 51–60 見たことのないものが生まれる

神が作った新種が、そのまま見た目を持って現れる。それまでは既存の絵の組み合わせだった世界に、知らない姿が混ざる。

- 語れること: 知らない生き物、季節で色が変わるもの
- 注意: 様式が崩れていないかを、公開前に必ず見る

### Day 61–70 世界の外側ができる

地域が増え、カメラが動く。庭が世界の全部ではなくなる。

- 語れること: 別の場所、高低差、そこにしかないもの
- 注意: 広さそのものを価値にしない。移動時間を引き延ばさない

### Day 71–80 自分の手を持つ

庭で植え、育て、作れるようになる。観測するだけだった観測者が、世界へ小さく触れられるようになる。

- 語れること: 植えたものが育つ、作れる、生き物が訪ねてくる
- 注意: 効率農場にしない。毎日の作業義務を作らない

### Day 81–90 世界に他者が現れる

NPCが暮らし、他の観測者の痕跡が見え、願いの結びつきが辿れるようになる。孤独と繋がりが同時に成立する段。

- 語れること: 住人、その人の記憶、誰かの足跡、自分の願いの行方
- 注意: 名前も人数も順位も見せない

### Day 91–100 世界が世界として閉じる

村の外に危険があり、100日の歴史が辿れるようになる。最後に、最初に見たものの意味が変わる。

- 語れること: 外の危険、100日の因果、はじまりの木の別の顔
- 注意: 戦闘を主役にしない。Day 100を完成として語らない

## 6. 毎日の伝え方

変化を伝える場所は創世日記だけとする。

- パッチノートにしない。機能名、バージョン、「追加しました」と書かない。
- 世界の内側から、神の短い言葉として語る。
- 何が変わったかを全部は書かない。観測者が自分で見つける余白を残す。
- 実装の都合（障害、再試行、仕様変更）を、そのまま物語にしない。
- 見逃しても損をしない。過去の日記と図鑑から、いつでも辿れる。

例として、同じ変更でも次のように書き分ける。

| 書かない | 書く |
| --- | --- |
| 「天候システムを実装しました」 | 「空が重い。雨というものを、はじめて降らせてみました」 |
| 「図鑑機能を追加しました」 | 「あなたが見たものを、書き留めておける場所を作りました」 |
| 「バグを修正しました」 | 「池の底が抜けていました。直しましたが、水は少し濁ったままです」 |

## 7. 届いているかの確認

「毎日変化を出した」ことではなく、「変化に気づかれた」ことを見る。

- 昨日との差を自力で見つけた観測者の割合
- 変化のあった対象が、その日のうちに観察された割合
- 見逃した変化に、後日たどり着いた割合
- 沈黙の日の離脱が、通常日と比べて増えていないか
- 時刻や天候に依存する変化で、取り逃しの不安が生じていないか

**変化を出した日に誰も気づかなければ、それは変化を出していないのと同じである。** 気づかれない日が続く場合は、量ではなく、変化の置き場所と言葉を見直す。
