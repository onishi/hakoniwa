# 複数の観測者が遊ぶ世界 — Day 1からDay 100

## この文書の位置づけ

同じ時刻に複数の人が訪れたとき、何を共有し、何を各自に残し、互いをどう感じるかを定める。Day 1の実装済みの範囲は [最初に作るゲームの仕様](FIRST_GAME_SPEC.md)、Day 100の到達点は [Day 100のゲーム仕様](MIDDLE_GAME_SPEC.md)、導入順は [体験の進化計画](EXPERIENCE_PLAN.md) と [開発ロードマップ](ROADMAP.md) に従う。

**体験の核は「同じ世界を、別々の視点から訪れる」こと。** 観測者の姿、オンライン人数、名前、位置、行動中のカーソルは表示しない。それでも世界日、風景、歴史、住人の暮らしを共有し、後には匿名の痕跡や願いから誰かの行為を感じられる。直接会うために同じ時刻へ集合する必要はない。

## 共有と個人の境界

| 状態 | 誰のものか | 他の観測者からの見え方 |
| --- | --- | --- |
| 公開済みの世界日、地形、存在、法則、創世日記 | 全員共通 | 同じ世界日の内容は同じ。公開後に途中状態を見せない |
| 時刻・天候、NPCの日課、世界規模の出来事 | 世界共通。導入された日以降 | 同じ条件で訪れた人には同じ状態と因果がある |
| 現在位置、向き、持ち物、庭、進行、個人的なNPCとの出来事 | 観測者ごと | 本人だけに見え、他人の移動や取得で消えない |
| 図鑑の観察記録 | 観測者ごと | 本人の記録を復元する。世界で確認された事実は匿名の共同記録にも反映し得る |
| 置いたもの、世話の跡などの共有痕跡 | 条件を満たした行為から生成 | 匿名の風景として見える。持ち主の位置やログイン状況を明かさない |
| 願い | 投稿者の記録であり、同意後は公開Issue | Day 1から公開先では読める。世界内での他者の願いの閲覧と共鳴はDay 80に導入する |

**共有世界を操作の奪い合いにしない。** 同じ木の実を二人が拾っても、それぞれの取得条件を満たせば双方が拾える。採集物、敵との遭遇、NPCとの会話や交換は、原則として各観測者の体験として判定する。誰かが先に来たために他人の一回の訪問が空振りになる有限在庫は設けない。世界の変化は、個人の操作がその場で地形や他人の庭を上書きする形では起こさず、公開済み世界日の更新や制約つきの共有痕跡として扱う。

## Day 1 — 同時にいても、それぞれ歩ける

二人が同じ時刻に「はじまりの庭」を開くと、同じ公開済みDay 1の地形と五つの存在を見る。二人の画面に相手の姿は出ず、同じタイルに立てる。同じ井戸を同時に調べても、どちらにも同じ観察文が出る。片方の移動、向き、メッセージ、日記画面の開閉は、もう片方の画面へ送られない。

ログイン済みなら位置と向きは各自のセーブに保存される。未ログインでも歩いて調べられる。願いは各自の7日間制限と明示的な公開同意で判定され、一人の投稿が他人の投稿枠を消費しない。Day 1には採集、置いたもの、他者の痕跡、リアルタイムの在席表示はない。公開Issueとして同意された願いを除き、他人が今いることを画面から知る手段はない。

現在のクライアントは入場時に最新の公開世界日を取得し、滞在中はその景色を保持する。世界日が公開された瞬間に、開いている画面へ差分を押し込む仕様ではない。境界をまたいで開いた二つの画面が一時的に別の世界日を示しても、それぞれは一つの公開済み世界日だけを描き、草地だけ翌日で存在だけ前日という混在はさせない。再訪または再読み込みで新しい日へ入る。

### Day 1の確認例

- 別アカウントA・Bが同時に井戸を調べ、互いの位置が見えず、双方に観察文が出る。
- Aの位置と向きを保存してからBが移動しても、Aの再訪位置は変わらない。
- Aが願いを送ってもBの7日間の投稿枠には影響しない。公開同意をしていない入力は共有されない。
- 世界日の公開が失敗した間は、二人とも最後の公開済みの世界へ入れる。

## Day 1からDay 100まで — 他者の存在が少しずつ残る

| 世界日 | 観測者から見た変化 | 同時に遊ぶときの約束 |
| --- | --- | --- |
| 1–8 | 同じ世界日を各自が歩き、拾う・持つ・置くが個人の行為として増える | 姿は見えず、移動や採集は競合しない。Day 6の「置く」はまず本人の再訪で復元される |
| 9–10 | 置いた行為の一部が、期限つきの匿名の痕跡として他者にも見える | 痕跡は他人が拾って奪う現物ではない。表示数と作成頻度を制限し、通路や重要物を塞がない |
| 11–20 | 各自の庭で耕し、植え、水をやり、採る | 庭の持ち主だけが配置と収穫を変える。留守中の成長はサーバー時刻で進み、他者の訪問数に左右されない |
| 21–40 | 区画と産出が増え、道具とクラフトが加わる | 地域は共通でも、素材の取得と製作は各自に成立する。大量取得による占有は持ち物上限とレート制限で抑える |
| 41–60 | 新種や動く生き物が世界に増える | 種と生態は共有する。生き物との接触や庭への来訪は個人の条件で判定し、誰かが追ったために他人の発見機会を消さない |
| 61–80 | 地形ごとの暮らし、NPCとのやりとり、他者の願いへの共鳴が生まれる | NPCの日課と世界の出来事は共通、会話と交換の結果は個人に残す。Day 80から他者の願いを世界内で読めるが、人気順や件数で並べない |
| 81–100 | 時刻・天候による違い、匿名の共同観察記録、100日の因果を辿れるようになる | 同条件の世界は一致する。第一発見の事実は残せるが、名前・順位・発見数を公開しない。痕跡や願いが後の創造へつながった経緯を辿れる |

これは観測者どうしの直接通信を増やす計画ではない。遠くの人の行為が景色や記録へ変わり、時間を置いて届く経路を増やす計画である。機能の公開日は各計画の品質基準に従い、世界日の番号を埋めるために未完成の共有機能を出さない。

## Day 100 — 同じ歴史を、それぞれの速度で読む

二人が同じ日の同じ水辺へ来れば、地形、天候、その時刻の生き物とNPCの日課は一致する。互いの姿や在席数は見えない。Aが素材を採ってもBの採集機会はなくならず、BがNPCへ渡した物はAの持ち物や個人的な会話履歴を書き換えない。Aが残した痕跡が公開対象に選ばれれば、Bが次に景色を取得したときに匿名の跡として見える。数十日後に戻った人も、痕跡の期限が過ぎていれば創世日記、図鑑、願いと後の創造の関係から当時の出来事を辿れる。

共同で観測した事実は世界の記録になるが、誰が先かを競う画面にはしない。個人の図鑑には自分がいつ何を見たかが残り、共同記録には初めて確認された世界日と地域、現在の解釈と訂正の履歴が残る。願いへの共鳴は、誰かの言葉へ静かに応じる行為であり、賛成票の合計や神の採用順位にはしない。

### 同時操作と更新の規則

1. **公開単位は世界日。** 新しい世界日、日記、世界の存在は一つの公開済み版として切り替える。長く滞在する画面には新しい日への移行を静かに知らせ、操作の途中で地形だけを差し替えない。
2. **個人の行為は本人に確定する。** 拾う、採る、作る、交換する結果はサーバーで本人に対して判定する。通信が失敗したときは成功したように見せず、再試行で二重取得させない。
3. **共有痕跡は条件つきで残る。** 作成された痕跡のうち、期限、密度上限、モデレーションを満たすものを公開対象に選ぶ。公開対象となった痕跡は、他の画面の次の取得で見える。Day 100までに通常の接続中は公開対象の確定から60秒以内の反映を目標とする。オフラインでは最後に取得した景色を読み取り専用で見せる。
4. **共有物への同時操作は他人を巻き戻さない。** 痕跡の作成は重複送信に耐え、競合しても一方の個人セーブを失わせない。共有風景へ加える変更は通行、観察、願いの掲示板を妨げない範囲に制限する。
5. **世界史への反映は集約する。** 庭や行為から創造へ渡す情報は匿名化して集約し、操作回数の多い一人が未来を決めないよう上限を設ける。公開前に検証し、変化の理由を後から辿れる形で記録する。
6. **同じアカウントの複数端末も混同しない。** Day 1の位置・向きは最後に成功した保存が残る。行為が増えた後は庭、持ち物、観察を独立して更新し、古い端末からの保存で新しい成果を丸ごと上書きさせない。

### Day 100の受け入れ条件

- 二人以上が同じ場所を同時に歩き、調べ、採集、NPCとのやりとりをしても、互いを遮らず個人の結果が混ざらない。
- 同じ公開世界日・時刻・天候の世界状態は一致し、日次公開の途中状態を誰にも見せない。
- 公開対象となった共有痕跡は接続中の別端末に60秒以内に届き、期限切れ・上限超過・不適切な痕跡は表示されない。
- 他者を感じる手掛かりはあっても、名前、現在位置、オンライン人数、発見順位、行動の生ログを推測できない。公開同意済みの願いは例外として明示する。
- 一人の連打や大量採集では、他者の取得機会、願いの扱い、世界の変化を占有できない。
- 新旧世界日の境界、通信断、二重送信、同一アカウントの複数端末を含めても、個人の成果と公開済みの世界史が失われない。

ここまで成立しても、直接会話、PvP、ギルド、共同作業への参加義務は入れない。誰かと同時刻に来られない人も、同じ世界の一員として遊べることを優先する。
