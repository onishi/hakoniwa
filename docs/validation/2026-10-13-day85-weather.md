# DAY 81〜85 時刻と天気候補の検証（2026-10-13）

進化テスト版に `seed-evolution-day85-weather.sql` を適用し、Worker version `b8a4985f-22d3-4cef-baa3-e0aeab0039d3` をデプロイした。本番の公開日は DAY 1 のまま維持する。

## 候補

- DAY 81: サーバーの日本時間から朝・夕・夜を定める。
- DAY 82: 夕方と夜の世界全体の色調を変える。
- DAY 83: 公開世界日に対応する晴・曇り・雨と雨の描画層を加える。
- DAY 84: 10日単位で芽吹き・盛夏・実り・霜を巡る。
- DAY 85: 林の地衣類の石から、雨の夕・夜は鏡石、それ以外は地衣類を採る。

## 確認結果

- ローカルDBでDAY 81〜85を順に公開し、各日の `/api/world` がその日を返すことを確認した。DAY85は日本時間7時、朝・雨・芽吹きになった。
- 時刻・天候の判定テストで、雨のDAY85の夕・夜だけ鏡石が選ばれ、朝と晴れの日は選ばれないことを確認した。
- ローカルと進化テスト版で、DAY85の朝に地衣類を採取し、持ち物に「地衣類」と表示された。
- ローカルのChrome画面で「7時 · 朝 · 雨 · 芽吹き」と地衣類の石が表示されることを確認した。
- 進化テスト版 `/api/world` はDAY85・朝・雨・芽吹きを返した。
- 画面を開いたまま時刻が変わっても表示が古くならないよう、表示中は60秒ごととタブ復帰時にサーバーの世界データを読み直す。
- `node --test worker/climate.test.mjs`、`npm run build`、`npm run lint`、`git diff --check` を通過した。

雨の夕・夜の採集結果は判定テストで検証した。実時間が朝のため、進化テスト版でのその条件の実採集は未実施。
