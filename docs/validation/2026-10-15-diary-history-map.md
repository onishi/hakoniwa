# 創世日記の過去地図閲覧（2026-10-15）

公開済みの日記から、その日の共有地図を開けるようにした。地形と存在を小さな地図に描き、前日の記録から新たに見える存在があれば名前を添える。個人の庭や持ち物は描かず、移行前の日は当時の撮影ではなく再構成であることを表示する。

## 確認

- `npm run build`、`npm run lint`、`git diff --check` を通過した。
- 進化テスト版のスナップショットAPIでDAY95からDAY96を比較すると、新たに見える存在は「草原の長い草」だった。DAY98からDAY99には新たな存在がなく、余分な発見を表示しない。
- 本番DAY1の共有地図は12×12、存在5件。進化テスト版DAY99は22×18、存在45件で、両方の地図データを取得できた。
- ブラウザーによる画面の目視確認はこの環境では実施できなかった。SVGの描画と操作導線はビルドで検証した。

DAY100の受け入れ条件は引き続き未達。過去の画像、地域と存在の厚み、日次シミュレーション再現などは別途検証する。
