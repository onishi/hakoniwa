# DAY 86〜90 観察と図鑑候補の検証（2026-10-13）

進化テスト版に `0021_field_observations.sql` と `seed-evolution-day90-field-guide.sql` を適用し、Worker version `66c3f159-401f-4ecb-9a99-0dd90a0b88d9` をデプロイした。本番の公開日は DAY 1 のまま維持する。

## 候補

- DAY 86: 小川に羽虫が現れ、天気と時刻のスロットから観察文を作る。
- DAY 87: 新しい操作を増やさず、神が何も書かなかった日を台帳に残す。
- DAY 88: 羽虫・小川の魚影・トンボの発見を観測者ごとに保存する。
- DAY 89: 発見済みの生き物だけを図鑑に表示する。
- DAY 90: 羽虫は地図から消え、羽の跡と「現在は確認されていない」記録が残る。

## 確認結果

- ローカルDBでDAY 86〜90を順に公開した。DAY86の羽虫の観察文には当日の晴れと朝が入り、DAY87の日記本文は空だった。
- DAY88に羽虫・トンボ・魚影を近くで観察すると、3件の発見が一度だけ記録された。
- DAY89の図鑑APIはその3件だけを返し、未ログイン時は空だった。総数や未発見の項目は返さない。
- DAY90の地図から羽虫が消えて羽の跡が現れた。以前に発見した羽虫の図鑑項目は「現在は確認されていない」状態になった。
- DAY90に初めて来た別の観測者は、羽の跡から羽虫を記録できた。遠距離からの観察、消えた羽虫への直接操作、同じ発見の二重記録は拒否・抑止された。
- 進化テスト版でもDAY90、DAY87の無言の日記、羽の跡からの発見と図鑑への保存を確認した。
- `npm run build`、`npm run lint`、`git diff --check` を通過した。
