# 毎日10分遊べる体験計画

この表は今後の公開候補の設計であり、進化テスト版の旧DAY 2〜50を反映した実装状況ではない。前倒しの理由、釣りの操作、公開ゲートは [DAY 50再設計](DAY50_REVISED_PLAN.md) に定める。公開済みDay 1は変えず、候補をDay 2から順に検証する。

## 10分の基本形

| 時間 | 観測者がすること | 画面から返すもの |
| --- | --- | --- |
| 0〜2分 | 日記と水面・草むら・庭の変化を見る | 今日気になる動きが一つ見つかる |
| 2〜5分 | その場所へ行き、観察またはアクションする | 魚影、虫、果樹、素材から結果が返る |
| 5〜8分 | 釣ったものを戻す、植える、作るなど一つ使う | 世界か庭に小さな変化が残る |
| 8〜10分 | 変化を見て、次に来る理由を見つける | 日記や生息場所に手掛かりが残る |

中心行為を一つ終えた時点で訪問は完結する。毎日ログインする義務、短い反射神経の判定、取り逃し、連続報酬を作らない。

## 公開前に確かめること

- 動きは存在と入手元の手掛かりになる。魚影・虫・果樹・岩は名前を読まずに見分けられる。
- 観察だけでも結果があり、釣りや捕獲を強制しない。
- 入手したものには、その場か同じ訪問で試せる使い道がある。
- 初見の観測者が説明なしで10分以内に中心行為を終えられる。
- 動きを減らす設定、音なし、キーボード、タッチでも同じ行為を完了できる。
- DAY 1の公開風景とデータを保ち、旧進化テストの履歴を新案の合格証拠に流用しない。
