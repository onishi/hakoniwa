# 毎日10分遊べる体験計画

## 目的

世界日が50まで進んでも「歩いて拾う」だけで終わらないよう、1回の訪問に小さな発見と結果を置く。10分は目標時間であり、毎日ログインする義務や連続報酬は作らない。来られない日があっても、次の訪問で同じ行為を続けられる。

## 10分の基本形

| 時間 | 観測者がすること | 画面から返すもの |
| --- | --- | --- |
| 0–1分 | 日記と庭の変化を見る | 前回から変わった一つの短い言葉 |
| 1–3分 | 近くの存在を一つ調べる | 入手元、状態、次に試せそうな対象 |
| 3–6分 | 一つの入手行為をする | 果樹から採る、道具で掘る、庭で収穫するなどの結果 |
| 6–8分 | 入手物を一つ使う | 植える、作る、置く、別の場所へ持っていく |
| 8–10分 | 変化を見て、日記か痕跡を残す | 置いた跡、育ち具合、次に戻る理由 |

毎日の中心行為は一つにする。10分の中で行為を三種類以上要求しない。中心行為を終えた時点で訪問が完結し、残りは発見として任意に遊べる状態にする。

## 「使い道がない」を公開前に止める条件

新しい存在や素材を公開する前に、次の三つを検証記録へ書く。

1. **入手元:** どの場所で、どの対象へ、どのアクションをするか。
2. **最初の使い道:** 取得後10分以内に試せる行為を一つ。
3. **次の使い道:** 庭、クラフト、配置、交換のいずれかへつながる行為を一つ。

「置ける」だけで終わる素材は、置いた結果が次の変化へつながるまで公開候補にしない。新種の見た目を増やす日も、既存の果樹・庭・道具のどれかへ接続する。

## 検証で見る指標

- 10分以内に中心行為へ到達した割合
- 入手したものを一度でも使った割合
- 次の訪問で戻る理由を観測者が言葉にできた割合
- 一日の中心行為を終える前に迷子になった割合
- 使い道のない持ち物が残った割合（目標は0）
- 10分を超えて任意に続けた訪問の割合

合格条件は「機能が存在する」ではなく、説明なしで入手元へ行き、使い道を一つ試し、結果を見て10分以内に訪問を終えられることにする。

## DAY 50の再構成方針

DAY 50のマップは、拾える物を並べる展示場にしない。果樹、道具小屋、岩、倒木、苗床、区画固有の採取場を入口として配置し、観測者が対象へ近づいてアクションすることで持ち物が増える。果物は庭へ戻って植えられ、鉱石と木材は家の前でクラフトに使え、区画固有の素材は置くか後続のレシピへつながる。

既存の落ちているだけの行は、対応する入手元へ置き換える。再構成後のDAY 50を合格にするには、10分の訪問で少なくとも「入手元へ行く → 一つ採る → 一つ使う」の循環が成立し、持ち物に使い道のないものが残らないことを確認する。
