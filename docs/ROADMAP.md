# HAKONIWA 今後の計画

この計画は世界の物語を固定するものではない。安全で継続可能な「創造の器」を段階的に作るための開発順序であり、各段階は品質基準を満たしてから次へ進む。

## Phase 0 — 箱庭RPGの原型（現在）

**目的:** トップビューのピクセル風RPGとして、村を実際に歩ける状態を作る。仕様は[最初に作るもの](FIRST_GAME_SPEC.md)。

- タイルマップ、衝突判定、カメラ追従、Yソート描画
- 四方向に歩く観測者と、正面の対象を調べる操作
- 調べた対象の短文を出すメッセージウィンドウ（会話システムは作らない）
- 住人のいない村マップと、自分の家への出入り
- 願いのローカル保存、神託・創世記・図鑑の最小表示
- キーボード、タッチ、ゲームパッドの操作対応

**完了条件:** 初見のテスターが説明なしで村を歩き回り、対象を調べ、願いを一つ結び、「この世界にはまだ何も無い」ことを欠陥ではなく余白として受け取る。

## Phase 1 — Day 1の縦切り版

**目的:** 原型の村を、本番相当の保存・配信経路に載せて全員で共有する。

- Cloudflare PagesのフロントエンドとWorkers API
- 匿名観測者ID、サーバー保存の願い、庭、図鑑
- D1のイベントログと世界スナップショット
- マップ配信と、`objects` への日次追加に耐えるスキーマ
- 移動・調査・痕跡の基本APIと、他者の足跡の匿名配信
- アクセシビリティ、エラー復旧、モバイル対応

**完了条件:** 複数端末の観測者が同じ村・同じ世界日を見つつ、互いの個人データを混同せず、再訪時に位置と状態が復元される。

## Phase 2 — 手動の創造運営

**目的:** AIを自動実行する前に、編集者が毎日の創造を安全に運営できるようにする。

- 構造化された創造イベントのスキーマ
- 下書き、検証、プレビュー、公開、ロールバック
- エンティティと因果関係のグラフ
- 願いのモデレーションと意味的な集約
- 「神の沈黙」を含む公開スケジュール

**完了条件:** 30日分の模擬運営でデータ矛盾や復元不能を起こさず、どの変化も創世記から追跡できる。

## Phase 3 — AI神の補助運転

**目的:** さくらインターネットVPSのcronから、AIが翌日の創造案を一つ提案する。

- 世界要約、歴史、伏線、願いを入力するコンテキスト生成
- JSONスキーマ、参照整合性、禁止操作、規模上限の検証
- 生態・経済への影響を試すステージングシミュレーション
- 人間による承認画面と差分レビュー
- モデル、プロンプト、判断理由の監査ログ

**完了条件:** 60回の提案で、本番DBへの直接権限をAIへ与えず、安全に採用・修正・保留できる。

## Phase 4 — 閉鎖世界テスト（Day 1–30）

**目的:** 少人数の観測者と、最初の一か月のリズムを検証する。

- 種、成長、魚などを段階的に導入
- 匿名の願い閲覧と「自分もそう願う」
- 発見日、場所、第一発見者、最終確認の記録
- 焚き火跡、水やり、置き物など期限付きの痕跡
- 通知ではなく創世記で復帰を支える導線

**判断指標:** 継続率だけでなく、発見の偏り、願いの安全性、神託の理解度、世界変化への驚きと納得の両立を見る。

## Phase 5 — 公開運営（Day 31–100）

**目的:** AI提案と人間監督による日次運営を安定化する。

- 承認不要にできる低リスク創造の限定的な自動公開
- 障害時の沈黙、公開延期、即時ロールバック
- 住人の登場と、そのとき必要な会話システムの新規実装
- 絶滅、突然変異、NPC文化など長期因果の試験導入
- 新規プレイヤー向けに歴史を圧縮せず読める案内
- バックアップ、費用上限、レート制限、荒らし対策

## Phase 6 — 自律する世界（Day 100以降）

**目的:** 神の直接創造だけでなく、法則から新しいものが生まれる世界へ進める。

- 遺伝、交配、生態系、技術伝播の決定論的シミュレーション
- NPCによる発明や文化形成
- 消滅種、化石、復元技術をまたぐ長期履歴
- 世界規模の共同イベントと、極めて稀な奇跡
- 「観測者」と過去の世界を巡る長期的な謎の段階開示

## 運営のガードレール

- AIは提案者であり、本番DB・Cloudflare・秘密鍵への直接アクセスを持たない。
- 創造イベントは追記型ログを正とし、修正も新しいイベントにする。
- 一日に公開する中心概念は原則一つ。複数の小変更はその因果に従属させる。
- 世界を壊す可能性がある変更、奇跡、主要な秘密の開示には必ず人間の承認を要する。
- ロードマップより世界の一貫性を優先し、必要なら神は沈黙する。
