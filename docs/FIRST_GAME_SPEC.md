# 最初に作るゲームの仕様 — Day 1「はじまりの庭」

## 1. 目的

最初の実装では、プレイヤーが小さな世界を歩き、そこにあるものを自分で見つけて調べる体験だけを作る。説明、案内、進行、収集といった要素は加えない。

世界日は `Day 1` から進まない。

## 2. 画面

画面には次のものだけを表示する。

- 一画面に収まるトップビューの世界
- プレイヤー
- 世界に置かれたオブジェクト
- メッセージウィンドウ一つ
- 上下左右の方向ボタン
- アクションボタン一つ

タイトル、ロゴ、Day表示、操作説明、神託、メニュー、ステータス、サブウィンドウ、通知は表示しない。ゲーム開始時のメッセージウィンドウは空とする。

## 3. 世界

世界は16:10の長方形を基準とし、画面内に全体を収める。草地、土の道、柵と、次のオブジェクトを配置する。

- はじまりの木
- 静かな池
- 小さな家
- 古い井戸

オブジェクトと世界の外周には衝突判定があり、プレイヤーは通り抜けられない。

Day 1には、NPC、動物、魚、火、花、種、昼夜、天候、戦闘、HP、レベル、経験値、通貨、アイテム、料理、農業、魔法は存在しない。

## 4. 操作

### 移動

- キーボードでは矢印キーを使う。
- 画面上では上下左右の方向ボタンを使う。
- 一回の入力で上下左右いずれかへ一タイル移動する。
- 移動しようとした方向をプレイヤーの向きとして保持する。

WASD、ゲームパッド、画面タップによる移動は初期実装の対象外とする。

### アクション

- キーボードではスペースキーを使う。
- 画面上ではアクションボタンを使う。
- プレイヤーが向いている隣接タイルを調べる。
- 隣接タイルにオブジェクトがあれば、そのメッセージをメッセージウィンドウへ表示する。
- オブジェクトがなければ、地面のメッセージを表示する。
- 移動しただけではメッセージを変更しない。

## 5. メッセージ

説明的なテキストは常設しない。文章はアクションを実行した結果として、メッセージウィンドウにだけ表示する。

| 対象 | メッセージ |
| --- | --- |
| はじまりの木 | 「世界で最初の木。葉の間で、風が眠っています。」 |
| 静かな池 | 「底はまだ見えません。生き物の気配はありません。」 |
| 小さな家 | 「小さな家です。中には、まだ誰もいません。」 |
| 古い井戸 | 「古い井戸です。水の音はしません。」 |
| 地面 | 「柔らかな土です。けれど、植えるものはまだありません。」 |

## 6. ビジュアル

- 16〜32px相当の論理タイルを基準にした、輪郭の明確なピクセルレトロ表現とする。
- 草、土、水、木材を中心とする限定パレットを使う。
- メッセージウィンドウは古いRPGを思わせる太い枠で表現する。
- 操作ボタンは文字による説明を置かず、形と記号だけで区別する。
- 小さな画面でも世界、メッセージ、すべての操作ボタンを同時に表示する。

## 7. 保存と通信

初期実装では状態を保存しない。再読み込みするとプレイヤーの位置、向き、メッセージは初期状態へ戻る。API通信も行わない。

## 8. アクセシビリティ

- すべての操作を矢印キーとスペースキーだけで完了できる。
- 画面上の操作ボタンには、視覚表示されない適切なアクセシブル名を付ける。
- キーボードフォーカスを明確に表示する。
- OSの「視差効果を減らす」設定では移動アニメーションを無効にする。
- タッチ操作領域は十分な大きさを確保する。

## 9. 受け入れ条件

- 初期表示に説明文、タイトル、Day表示、メニュー、サブウィンドウがない。
- 表示されるウィンドウは、空のメッセージウィンドウ一つだけである。
- 矢印キーと方向ボタンで上下左右へ移動できる。
- オブジェクトと外周を通り抜けられない。
- オブジェクトに隣接してその方向を向き、スペースキーまたはアクションボタンを押すと、対応する文章がメッセージウィンドウに表示される。
- オブジェクトがない方向でアクションを実行すると、地面の文章が表示される。
- 320px以上の画面幅で世界、メッセージウィンドウ、操作ボタンを利用できる。
