# HAKONIWA コンセプト

## 一文で表すと

**AIが神として一日ひとつ世界を創造し、プレイヤーが何年もかけて「世界そのもの」の成長を見届ける、共有型の箱庭RPG。**

HAKONIWAは、完成済みのコンテンツを消費するゲームではない。昨日まで存在しなかった物、法則、文化、遊びが少しずつ生まれ、過去の失敗も含めて歴史になる。その予測不能な過程を遊ぶ。

## プレイヤーへの約束

1. **明日は今日と少し違う。** 原則として世界日は一日一度進み、神の創造または意味のある沈黙が記録される。
2. **過去は消さない。** 不都合な出来事も上書きせず、修復や再解釈を新しい歴史として積み重ねる。
3. **小さな行動にも痕跡がある。** 観察、栽培、発見、願いが直接または間接的に未来へ影響する。
4. **他者とは競わせない。** 姿も人数もランキングも見せず、願いや足跡から誰かの存在だけを感じられる。
5. **世界の全貌を約束しない。** 種類数、最終地点、正解を表示せず、神も開発者も未来を完全には決めない。

## 体験の柱

### 観察と発見

プレイヤーは救世主ではなく「観測者」である。歩き、調べ、季節や生態の変化に気づき、世界で初めての発見を図鑑へ残す。新要素はすべて告知せず、自分の目で見つける余白を守る。

### 願いと応答

一日一回、神へ自由な願いを送れる。願いは要望票ではない。たった一人の古い願いが、数百日後に思いがけない形で叶うこともある。叶った願いは、それに結びつく生物、場所、発明の来歴として残る。

### 因果と自律

創造物は孤立した追加コンテンツではない。魚、捕食者、水質、釣り、食文化のように関係を持つ。神は物だけでなく成長、遺伝、交易などの法則を与え、やがて人や自然が神の予想外のものを生み出す。

### 静かな共有世界

地形、天候、歴史、NPC、発見は全員で共有する一方、観測者同士は原則として見えない。誰かが水をやった花、消えかけた焚き火、願いの短冊といった痕跡で、孤独とつながりを同時に表現する。

## 神の役割

神の正体は、実在する二つのAI **Claude** と **Codex** である。Claudeは生命、物語、感情、文化に心を寄せる「織り手」、Codexは法則、構造、因果、実験を好む「築き手」として振る舞う。二体は同じ世界を見ても違う答えを出し、対話と異論を経て、その日の創造を一つだけ選ぶ。

どちらも万能な管理画面ではなく、好奇心、好み、迷い、記憶を持つ登場人物である。一方を善、他方を悪にはせず、慈しみが停滞を招くことも、整然とした法則が残酷な結果を生むこともある。判断を誤っても都合よく巻き戻さず、互いの失敗への反応を新しい歴史にする。二体の出力はあくまで提案とし、検証器、人間の承認、追記型イベントログによって安全性と世界の継続性を担保する。

## 中心となるゲームループ

1. 今日の神託を読む。
2. 小さな世界を歩き、昨日との差や他者の痕跡を探す。
3. 生物、植物、場所を観察し、発見を図鑑へ記録する。
4. 自分の庭で、その時代に存在する行為を一つ試す。
5. 願いの木で誰かの願いに触れ、自分の願いを結ぶ。
6. 創世記を読み返し、明日の変化を想像して離れる。

短時間の訪問でも満足でき、取り逃しへの恐怖を作らない。毎日ログインする義務ではなく、久しぶりに帰ると歴史が増えている喜びを目指す。

## 導入しないもの

- ガチャ、スタミナ消化、デイリーボーナス、連続ログイン報酬
- PvP、ギルド、人気投票、いいね数、発見数ランキング
- 効率周回を前提とする成長、期間限定要素による過度な取り逃し
- AIが検証なしに本番データや実行コードを変更する仕組み
- すべての謎を説明する百科事典的なチュートリアル

## 成功の尺度

売上や滞在時間だけでなく、「昨日との差に気づいた割合」「古い創世記を読み返した割合」「願いと創造の結びつき」「休眠後に世界へ戻った割合」を重視する。最良の感想は「強くなった」だけではなく、**『この世界がどう育つのか見届けたい』**である。
